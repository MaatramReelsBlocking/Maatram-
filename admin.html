Admin commands

Set points
Type any number and confirm. Use this to correct an inflated score back to what the user actually earned. Admin writes skip the +100 per-write cap.
Zero
Sets this month's points to 0. Lifetime total is left alone.
Kick
Force sign-out. The account stays valid — the next page load logs them out once and sends them back to the sign-in screen. Use for a live study-room disruption.
Ban
Freezes the account. Every gated page refuses to open, the user is signed out immediately even mid-session, they cannot write points, and they disappear from the leaderboard. Asks for a reason, which is shown to them.
Unban
Lifts the ban. The account works again on the next sign-in.
Lock
Puts the passphrase screen back up without signing out. The console also locks itself after five minutes with no clicks or keys.
Delete
Removes the user document — points, role, class link, archive. The Google account can sign up again as a new user. Not reversible.
